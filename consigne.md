# Bachelor B1 - Langages du web - Front - Examen

## Objectifs

L'objectif principal est la réalisation d'une page web, en mettant en oeuvre les technologies HTML et CSS.

Le but n'est pas de "copier-coller" une page déjà existante, mais de réaliser une intégration de page à partir de son propre code.

L'idée sera d'appliquer les techniques vues ensemble :
- réalisation d'une structure sémantique en HTML
- lien entre la page HTML et la feuille de style CSS
- inclusion d'une police (Google Font)
- inclusion d'images
- réalisation de liens
- application d'un layout (techniques CSS appropriée)
- application de règles CSS de mise en forme (couleur, box model, animation)

## Modalités

Le projet se fait de manière individuelle.
La date limite de rendu est le 20/01/2025 à 00:00.

## Sujet

Le sujet est laissé globalement libre.
L'idée est une réalisation qui pourrait intégrer votre e-portfolio professionel.
Il faut donc privilégier les sujets en rapport avec votre projet professionnel.

Voici des exemples de choix de sujets :
- une recette de cuisine
- une présentation d'une structure professionnelle ou associative
- votre cv
- un reportage journalistique

## Livrables

Le projet devra être rendu sous la forme d'une archive déposée dans Mootse ou via WeTransfer.

Cette archive devra contenir :
- les sources HTML et CSS
- les éventuelles autres ressources, type images permettant l'affichage de la page
- un document rédigé de type documentation technique, qui explique les intentions et les choix d'implémentation qui ont été mis en oeuvre
