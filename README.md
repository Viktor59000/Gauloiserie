# La Gauloiserie: A Taste of Traditional French Cuisine 🇫🇷

## Bienvenue! 👋

Welcome to La Gauloiserie, a website dedicated to showcasing and sharing authentic recipes from the French "terroir." This project aims to evoke the warmth and conviviality of a family meal in a rustic countryside setting.

## Discover the Flavors 🍽️

La Gauloiserie features a collection of classic French dishes, each presented with detailed instructions and mouth-watering visuals. Currently, the site includes:

*   **Entrées (Appetizers):** A selection of delightful starters to whet your appetite.
*   **Plats (Main Courses):** Hearty and flavorful dishes that represent the heart of French cuisine.
*   **Desserts:** Indulgent sweets to complete your culinary journey.
*   **Boissons (Drinks):** Perfect beverage pairings to enhance your meal.

Each category contains 3 recipes for now.

## Key Features ✨

*   **Visually Appealing Design:** A warm color palette with rustic brown tones (#8B4513 and #A0522D) reminiscent of a traditional wooden table.
*   **Unique Typography:** The "Cookie" font for the logo evokes a sense of familial warmth, while "Fredericka The Great" adds an artisanal and authentic touch to the text.
*   **Interactive Elements:** Subtle animations and hover effects to engage users and create a dynamic browsing experience.
*   **Responsive Layout:** A media query adapts the site's layout for optimal viewing on different screen sizes (up to 1024px).
*   **Comment Section:** Each recipe page includes a comment section for users to share their feedback and experiences.
*   **"Back to Top" Footer:** The footer contains an arrow icon with a smooth animation to allow users to navigate to the top of the page easily.
*   **Social Media Links:** The footer also contains links to social media pages.

## Technical Details ⚙️

*   **Architecture:** The site consists of 13 HTML pages, all styled with a common CSS file for visual consistency. The `index.html` page utilizes `banner.css` for unique homepage elements.
*   **Image Management:** Images are organized in the `images` folder, categorized by dish type (entrée, plat, dessert, boisson). Profile pictures for comments are stored in the `images/profil` subdirectory.
*   **Navbar:** The navbar includes a text-logo that links back to the `index.html` page, followed by a list of links to the various recipes.
*   **Banners:** Banners use CSS gradients and subtle animations to attract user attention.
*   **Metadata:** The site uses Google Fonts for custom typography and includes relevant CSS links.
*   **Comments Section:** Comments are displayed in cards and formatted with `<h4>` and `<h5>` tags to improve SEO.

## Under the Hood 💻

The CSS code is carefully structured to target specific elements and achieve the desired styling. Key CSS techniques include:

*   **Flexbox:** Used extensively for aligning and arranging elements.
*   **Z-index:** Used to ensure the navbar stays above other elements on the page.
*   **Media Queries:** Used to adapt the site's layout for different screen sizes.
*   **SVG Icons:** Font Awesome icons used in the footer and recipe sections are embedded as SVGs for scalability and customization.
